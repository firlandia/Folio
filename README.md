# Folio · sitio web

Sitio público de Folio (*Read. Collect. Think.*), publicado con GitHub Pages en
https://firlandia.github.io/folio/

- `index.html`: presentación, funciones, precios y preguntas.
- `privacidad/`: aviso de privacidad.
- `terminos/`: términos de uso.
- `reembolsos/`: política de reembolsos.

Todas las páginas están en español e inglés. El idioma se elige según el navegador y se
puede cambiar con el botón de arriba. También se puede forzar con `?lang=en` o `?lang=es`.

El código de la app está en el repositorio privado `folio-windows`.
